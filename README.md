### Записи о запросах
### Запись №2 09.10.26

- **Что я хотела сделать:** чтобы на вкладке появилась иконка сайта.
- **Что я спросила:** «Что нужно исправить формат картинки или код?»
- **Что ответил ИИ:** объяснил, что нужно сделать маленькую квадратную картинку и подключить её через тег <link rel="icon"> в <head>.
- **Что я изменила:** в коде ИИ был img.png — переименовала. 
- **Как проверила:** обновила сайт и иконка появилась.

### Запись №2 07.10.26
- **Что я хотела сделать:** понять для чего нужен conteiner. 
- **Что я спросила:** «Объясни суть container и зачем он нужен?»
- **Что ответил ИИ:** рассказал, что .container — это главный контейнер страницы, который ограничивает максимальную ширину контента (max-width) и центрирует его по середине экрана с помощью margin: 0 auto.
- **Что я изменила:** Убедилась, что все мои секции лежат внутри этого контейнера, чтобы сайт не растягивался на весь экран. 
- **Как проверила:** открыла сайт на широком экран и проверила все ли на своих местах.

### Запись №2 17.10.26
- **Что я хотела сделать:** сделать красивую подсветку у стрелки.
- **Что я спросила:** «Помоги разобраться с подсветкой у стрелки, как её сделать?»
- **Что ответил ИИ:** подсказал использовать псевдокласс :hover для изменения состояния и свойство filter: drop-shadow для создания свечения вокруг картинки. А для плавности — transition.
- **Что я изменила:** добавила в CSS код для .arrow-link:hover с эффектом увеличения и зеленым свечением. 
- **Как проверила:** навела мышку на стрелку на сайте — она стала больше и засветилась.

### Запись №2 21.10.26
- **Что я хотела сделать:** расставить стикеры с лягушками в секции «Философия» и «Уникальность» так, чтобы они красиво смотрелись по краям, но при этом не закрывали текст.
- **Что я спросила:** «Как сделать, чтобы стикеры стояли по бокам, но не наезжали на буквы?»
- **Что ответил ИИ:** объяснил, что для этого нужно использовать абсолютное позиционирование (position: absolute), задать координаты для каждого стикера, а самому тексту добавить z-index, чтобы он всегда оставался поверх картинок.
- **Что я изменила:** добавила стикерам position: absolute и настроила параметры top, left, right, bottom, чтобы они висели в нужных углах. А тексту задала z-index: 2, чтобы он перекрывал картинки.
- **Как проверила:** обновила страницу — стикеры разлетелись по краям, а текст остался читаемым.
